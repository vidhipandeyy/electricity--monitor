#### Smart Electricity Usage Monitor ⚡

A data-driven web application built with **Python** and **Streamlit** to track, analyze, and visualize electricity consumption from structured usage datasets (data.csv). 

#### Key Features

* **Interactive Analytics Dashboard (app.py):** Visualizes power consumption trends, peak usage intervals, and comparative metrics using Streamlit.
* **Dataset Processing (data.csv):** Parses historical electricity readings to highlight consumption anomalies and efficiency opportunities.

#### Tech Stack

* **Language:** Python
* **Framework & Libraries:** Streamlit, Pandas
